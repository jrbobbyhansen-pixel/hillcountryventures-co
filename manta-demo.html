Try Manta Tools Live

A simulated terminal running all 15 Manta CLI tools. Type any command below or click a tool name to see it in action. Each tool responds with realistic output — no installation required.

Tools

How to use

Type a command in the terminal below and press Enter. Try toc --help for any tool, or click a tool name above to auto-type a demo command. Type help to list all tools, or clear to reset.

manta-demo ~ $
Next Steps

Install Locally

All Manta tools are open source on GitHub. Install any of them with pip:

pip install manta-tools

Or clone individual repos from github.com/jrbobbyhansen-pixel.
